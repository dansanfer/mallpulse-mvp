# Histórico de alterações

## 1.1 - 2026-11-14

- API Grape com persistência Sequel/PostgreSQL.
- Recomendação por regras (H/L/C/S) com BrasilAPI e Open-Meteo.
- Check-in idempotente com token emitido pelo backend (HMAC).
- Autenticação Supabase (JWT/JWKS).
- Frontend integrado; mocks removidos e convertidos em seed simulado.

## 1.0 - 2026-11-13

- Consolidação dos seis requisitos da primeira entrega.
- Inclusão dos três protótipos e do fluxo de navegação.
- Especificação de dados, regras de afinidade e integrações.
- DDL de referência e PDF da entrega.
